# 公文写作 · gongwen-xiezuo

中文公文写作 Skill：中国当代八股文，每段小标题及段内句子工整对仗，擅长用比喻。拟稿、标题、过渡、疯狂引用习语。支持本地 Word 资料导入，可学习你的文风。

**[下载《公文写作词句应用大全》Word 全文](https://raw.githubusercontent.com/chutiankuo819-hash/gongwen-xiezuo/main/references/%E5%85%AC%E6%96%87%E5%86%99%E4%BD%9C%E8%AF%8D%E5%8F%A5%E5%BA%94%E7%94%A8%E5%A4%A7%E5%85%A8%EF%BC%88500%E9%A1%B525%E4%B8%87%E5%AD%97%EF%BC%89.docx)** · **[下载完整写作包（ZIP）](https://github.com/chutiankuo819-hash/gongwen-xiezuo/archive/refs/heads/main.zip)** · [阅读写作说明](SKILL.md)

这份写作包可以交给不同的 AI 助手，用来起草通知、请示、报告、函、纪要、讲话和工作总结，也可以只改一组小标题或一处过渡。附送的《公文写作词句应用大全》共500页，15篇全文都可用于写作。公开 Word 已清理隐藏编辑者及软件保存标识，正文和版式保留原貌。

## 安装与使用

**支持 `SKILL.md` 的助手。** 下载完整写作包，解压后按所用工具的技能导入方式，导入含 `SKILL.md` 的目录。保留目录里的 `references` 和 `scripts`，这样助手既能读原书，也能在允许执行 Python 的环境里按主题查词。

**支持文件上传的对话助手。** 把 Word 全文和 `SKILL.md` 上传到同一对话。如果助手只收 Word，可以把[写作说明](SKILL.md)的正文粘贴到对话里。需要按出处挑选习语时，再上传完整包中的 `references/xi-phrases.jsonl`；如果大文档超过助手的读取范围，可按本次稿件的需要上传几个相关章节。可以直接这样提要求：

> 请参考我的上季度汇报，沿用我的标题节奏和称谓，用下面的新材料写本季度汇报。写已办事项时查原书的成果用语，写下季度安排时查工作部署提纲。同级标题各有一个判断，比喻取同一系列。两部分之间从书里挑一句合适的过渡，习语自然用到正文里。

## 自带资料

**主要写作参考是随包附送的《公文写作词句应用大全》Word 全文。** 起草正文、拟小标题、改句和写过渡时，优先从这本500页的书里找词、找句、找提纲。全书15篇均可按篇阅读、按原句检索，并可回到原段查看上下文；需要说明来源时，列出篇名、小节及例号或段号。习语索引补充有出处的表达，45条原创示例示范怎样组织文稿。个人 Word 范文可另行导入，主要用来贴合作者文风。

### 全书15篇怎样用到一份稿里

按文种和段落用途跨篇选材。例如，一份工作汇报可以从“成果类词语与应用实例篇”选成效表述，从“工作部署篇”借计划的小标题，转场时再翻“比喻类词句与应用篇”里的“比喻对偶过渡句 41 例”。下列词句都能在随附 Word 正文里找到。

| 要写的部分 | 查哪一篇 | 原书中的例子及用法 |
|---|---|---|
| 总结工作进展 | 成果类词语与应用实例篇 | “基本形成”“稳步提升”是不同判断。有初步做法可写前者，有前后对比材料方可写后者。 |
| 拟定部署小标题 | 工作部署篇 | 原文一条是：二是打好转型升级“组合拳”，释放改革创新牵引力。题材合适时可以沿用；换成其他业务时，核准动作和目标。 |
| 从职责转到服务安排 | 比喻类词句与应用篇 | “比喻对偶过渡句 41 例”第26例原句是：守好“责任田”，站好“服务岗”。上段写职责，下段接具体岗位安排。 |
| 选春季活动致辞的诗句 | 季节篇 | 朱熹《春日》：“等闲识得东风面，万紫千红总是春。”引用后可引出本次活动中实际展出的作品。 |

需要指明出处时，可给篇名、小节、例号或 Word 段落编号。正文原句、原书小标题、按新材料化用的标题分别注明。

### 辅助选词：习语和原创示例

- **306个习语短语**按9类用途组织，含50个精选词例。统计覆盖1,201份本人讲话、文章、书信及单次讲话节选，另将1,579篇报道中的直接引语作为补充。两组分别计数，每项可按例篇和链接回查出处。另有12条当代讲话的主题线索和3条兼有原典、讲话出处的古诗古语。[讲话专栏](https://www.12371.cn/special/xxzd/jh/) · [《求是》署名文章专栏](https://www.qstheory.cn/zt2019/qskfzsjwz/index.htm)
- **45条原创示例**覆盖拟标题、写比喻、选过渡和常见文种，可按用途单独查阅。[标题与段落示例](references/writing-patterns.md)

## 可选：用 Python 检索

在解压后的技能目录中运行，使用 Python 3 标准库。可列全书目录、通读整篇、查原句上下文或指定一段原文：

```text
python scripts/read_original.py --list-chapters
python scripts/read_original.py --chapter 工作部署篇
python scripts/read_original.py --chapter 季节篇 "等闲识得东风面" --context 2
python scripts/read_original.py --range W10531:W10545
python scripts/search_phrases.py --source bundled --section 比喻对偶过渡句
python scripts/search_xiyu.py --preferred --length 5 学习
python scripts/search_xiyu.py --sentences 用典
```

`W` 开头的编号是 Word 从1起算的段落号，包含标题、表格内段落和空段。引用某段可用 `--paragraph W01676 --context 2` 回看上下文。

## 学习你的文风

挑一份你满意的近期定稿，最好和这次要写的是同一文种。让助手看标题怎样落观点、段首怎样起笔、惯用哪些称谓、写完成进度时把话说到什么程度，再用新材料仿写。旧稿中的人名、数字、政策和成绩仍只属于旧稿。

普通对话助手可直接读取上传的范文；支持脚本时，可运行下面的命令分析文风。若也想按词句检索自己的材料，可另行导入本地索引。扫描图片需先识别文字；替换已有词句索引时显式加 `--replace`。

```text
python scripts/learn_style.py "范文一.docx" "范文二.docx" --genre 工作汇报
python scripts/import_docx.py "自己的写作参考.docx"
python scripts/search_phrases.py --source local --list-chapters
```

范文分析默认生成 `references/local-style.md`。此后起草同类稿件时，助手先读这份简表；要更新已有简表可加 `--replace`，只想看分析结果可加 `--stdout`。
